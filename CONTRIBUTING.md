# Contributing

1. Keep the site fully static and accessible without client JavaScript.
2. Derive quantitative claims from `src/data/evidence.json`; never type a new
   result into prose without adding a test.
3. Keep development-only results explicitly labeled and preserve limitations.
4. Run `npm run check`, `npm test`, and `npm run build` before review.
5. Do not deploy or change Pages visibility as part of an ordinary content PR.
